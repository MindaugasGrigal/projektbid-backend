# Pomodoro Productivity Tool

This repository contains a simple command line Pomodoro timer with basic task
tracking. The tool allows you to create tasks, start Pomodoro sessions and view
statistics of completed sessions.

## Features
- 25 minute focus and 5 minute break cycles (configurable)
- After 4 cycles a longer break is triggered
- Task list with planned session count and completion tracking
- Daily statistics of completed sessions

Run `python -m pomodoro.cli --help` for command usage.
